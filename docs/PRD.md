# PRD — 工作台主页（产品介绍站）

> 版本 v1.1 · 2026-10-07 · 静态站点（index.html + 本地截图资源）
> 上游项目：P-工作台3（/Applications/工作台3.app，v3.8.108）

---

## 1. 背景

P-工作台3 是一款已经稳定迭代的 macOS 原生个人工作台（日程 · 待办 · 目标 · 项目 · 人生时间轴 · 统计 · 专注 · AI），历经 v3.0 → v3.8.27 上百轮迭代，但**没有任何对外介绍页面**——功能、架构、设计理念只存在于代码与记忆里。需要一个「主页网站」：

- 向使用者（自己 / 朋友 / 潜在用户）一句话讲清「这是什么、有什么」；
- 展示三明治架构与「零依赖、本地优先」的工程特点；
- 体现与 App 本体一致的 macOS 设计质感（主页本身就是产品的第一张名片）。

## 2. 目标与非目标

**目标**
1. 一个可直接双击打开的静态主页，完整介绍工作台的功能与特点；
2. 视觉语言与 App 本体同源（同一套色彩 Token、圆角、阴影、字体栈），亮/暗双色；
3. 桌面 + 移动端均可正常浏览；
4. 交付 PRD / UI 方案 / 技术路线三份文档，与实现同仓。

**非目标**
- 不做下载分发、账号、评论等后端能力；
- 不做管理后台或多页路由；
- 不重复罗列 App 的全部 200+ 交互细节，只呈现「能让访客 3 分钟建立认知」的层级。

## 3. 目标用户与场景

| 用户 | 场景 | 关注点 |
|---|---|---|
| 产品主人（自己） | 向朋友展示 / 简历作品集链接 | 有面子、准确、有设计感 |
| 潜在使用者 | 决定要不要试用 | 功能全不全、数据安不安全、装起来麻不麻烦 |
| 技术同行 | 评估实现方式 | 架构是否合理、技术选型亮点 |

## 4. 内容策略（信息架构）

访客按「是什么 → 有什么 → 怎么做的 → 凭什么信」四层递进，对应六个区块：

| # | 区块 | 内容 | 对应 App 事实来源 |
|---|---|---|---|
| ① | Hero 首屏 | 一句话定位 + 关键数字 + 总览页实景截图（亮/暗双版） | 运行中 App 截图 |
| ② | 七大页面 | 总览/行动/项目/目标/人生/专注/统计 每页一张功能卡 | web/js/features/ 22 个模块 |
| ③ | AI 能力 | 对话式助手、三智能体、长期记忆、用量统计、上下文注入 | v3.1~v3.8 AI 迭代史 |
| ④ | 架构 | 三明治图（Swift 壳 / Web 前端 / Python wbcore）+ 端口族 | docs/01-ARCHITECTURE.md |
| ⑤ | 工程特点 | 零依赖、本地优先、自动备份、原生通知、全局快捷键、多端适配 | 版本史 |
| ⑥ | 页脚 | 版本、文档链接、免责说明 | — |

**功能清单口径**（主页展示的下限集合，全部有代码实证）：

- **总览**：问候语、8 张 KPI 指标卡、今日待办、今日日程、项目进展、可拖拽调整的卡片网格、3D 换装形象
- **行动**：周/月/年三档日历、快捷添加、标签体系、拖拽改期、重复任务、超期红显、外部日历订阅（ICS/CalDAV）
- **项目**：甘特图 + 表格双视图、跨层级依赖引擎、子任务、里程碑、工作日排期引擎、列设置/排序、项目模板、实施进度
- **目标**：人生之花平衡轮、目标进度综合口径、打卡圈、目标评分
- **人生**：时间轴、人生节点、纪念日、生日
- **专注**：正/倒计时、秒针拖尾刻度环、任务池拖拽关联、沉浸模式、趋势图、当日时间轴
- **统计**：14 张统计卡、年度热力图、项目进展、专注统计、AI 用量
- **AI**：对话式多会话、Hermes/Muse/Sage 三智能体、轻量 Markdown 渲染、长期记忆蒸馏、每周总结、总览侧栏 + 顶栏快问双入口、OpenAI 兼容代理
- **系统层**：macOS 原生窗口/菜单/通知（可推迟）、全局快捷键、自动 zip 备份（频率/份数/目录可配）、回收站三档软删、亮暗主题、日历 ICS/CalDAV 订阅、v2 一键迁移

**验收标准**
- [ ] 双击 index.html 直接打开即可完整浏览（file:// 协议无报错）；
- [ ] 亮/暗两套主题下所有区块对比度可读；
- [ ] 1440 / 1024 / 390 三档视口无横向滚动、无内容裁切；
- [ ] 功能描述与 App 实际能力一致，不夸大（已移除 v3.8.88 中不存在的「手机版视图」表述）；
- [ ] 零外部请求：无 CDN、无字体下载、无第三方外链（截图为本地 assets，图标全部内联 SVG）；
- [x] **截图零真实数据**：8 张截图全部来自虚构演示库（人设「小北」，由 `tools/make_demo_data.py` 生成），可直接公开。
