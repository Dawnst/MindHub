# 技术路线 — 工作台主页

> 配套 PRD v1.0 / UI 方案 v1.0

---

## 1. 总体选型：单文件零构建静态页

延续工作台家族的技术基因（App 本体 = 零构建 Web 前端 + Python 纯标准库服务），主页采用**单文件 `index.html`**：

| 决策点 | 选择 | 理由 |
|---|---|---|
| 形态 | HTML 单页（CSS/JS 全内联）+ 本地截图 `assets/` | 双击即开（file:// 可用）、拷贝即分享、无构建链 |
| 框架 | 无（原生 DOM + 少量 JS） | 页面是静态内容展示，框架是负资产 |
| 依赖 | 零外部请求 | 无 CDN/字体/图片外链，离线可看，无隐私外泄 |
| 图标 | 内联 SVG（stroke 风格手绘） | 对齐 App 图标库，可随 `currentColor` 换主题色 |
| 字体 | 系统字体栈 | macOS/Win/手机各用最佳系统字体，零下载 |

## 3. 关键技术点

### 3.1 主题系统
- Token 双套：`:root` 亮色 / `html[data-theme=dark]` 暗色（变量名与 App 本体一致）；
- `<head>` 内联脚本：`localStorage('hp-theme')` 优先，否则 `matchMedia('(prefers-color-scheme: dark)')`，在首帧渲染前挂好 `data-theme`；
- 切换按钮写回 localStorage；可选 `auto` 档监听系统切换。

### 3.2 滚动交互
- **锚点高亮**：IntersectionObserver（`rootMargin: -40% 0px -55%`）观察六个 section，命中即点亮对应导航项；
- **入场动画**：同一 Observer 以 `.reveal` 类标记待入场元素，进入视口加 `.in`；
- **导航玻璃态**：`scroll` 监听（passive + rAF 节流）> 8px 切换 `.scrolled`；
- 平滑滚动用 CSS `scroll-behavior:smooth` + `scroll-margin-top` 预留粘性导航高度。

### 3.3 实景截图接入（v1.1 起）
- 截图链路：**虚构演示数据**——`tools/make_demo_data.py` 生成 `/tmp/wbdemo` 演示库（人设「小北」，凭据位全假化、末尾自带泄漏自检）→ `server.py --port=8392 --data-dir=/tmp/wbdemo` 起一次性实例 → Playwright（1280×800，`device_scale_factor=2`），`WB.showPage()` 逐页导航后截视口——纯客户端切页，不产生数据写入，也绝不触碰 8383 正式库与快照实例；
- Hero 亮暗双版（`shot-overview.png` / `shot-overview-dark.png`）同挂 DOM，CSS 按 `data-theme` 显隐，换主题即换截图；
- 功能卡缩略图 `object-fit:cover` 顶对齐统一 16:10，`loading="lazy"` 延迟加载，首屏只拉总览一张。

### 3.4 内容数据化
- 七大页面卡、工程特点卡的文案收在 JS 顶部的 `PAGES` / `TRAITS` 数组，渲染函数一次性生成 DOM——**App 功能演进时改数组即可，不碰 HTML 结构**。

### 3.5 可访问性与降级
- 语义化标签（header/nav/main/section/footer）、对比度按 WCAG AA 校验文字三级色；
- `prefers-reduced-motion` 关闭入场动画与圆环生长；
- 无 JS 降级：`<noscript>` 让所有静态区块直接可见（导航高亮/入场动画/数据化卡片不工作，正文仍完整可读）。

## 4. 部署与分享

| 方式 | 命令 | 场景 |
|---|---|---|
| 直接打开 | 双击 `index.html` | 本机浏览 |
| 局域网分享 | `python3 -m http.server 8800` | 同一 Wi-Fi 下手机预览 |
| GitHub Pages | 仓库 Settings → Pages → main 分支 /root | 对外链接（见 README 的推送步骤） |
| 静态托管 | 任何静态目录服务（Nginx / 对象存储静态站） | 自有域名 |

## 5. 验证方案

1. **静态检查**：`python3 -c` 快速解析 HTML 结构完整性（标签配对、锚点存在性）；
2. **Playwright 走查**（本机既有 chromium 链路）：
   - 1440 / 1024 / 390 三档视口截图，检查无横向滚动、无裁切；
   - 亮/暗两主题各截一轮；
   - 点击导航锚点，断言对应 section 进入视口且导航项高亮；
   - 断言零网络请求（拦截非 `file://`/`localhost` 请求即失败）；
3. **回归口径**：文案与 P-工作台3 实际功能一致（比对 README + 版本史）。
