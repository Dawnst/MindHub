# UI 方案 — 工作台主页

> 配套 PRD v1.0 · 设计语言与 P-工作台3 本体同源

---

## 1. 设计语言：向 App 本体看齐

主页直接复用工作台的视觉 Token（取自 `web/css/tokens-base.css`），访客从主页点进 App 不会有「两个产品」的割裂感：

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg` | `#eef0f4` | `#1a1a1e` | 页面底 |
| `--panel` | `#ffffff` | `#232327` | 卡片 |
| `--text / text2 / text3` | `#1d1d1f / #5d5d63 / #8e8e93` | `#f5f5f7 / #b8b8c0 / #7c7c85` | 文字三级 |
| `--primary` | `#007aff` | `#0a84ff` | 主操作 / 链接 |
| `--border` | `rgba(0,0,0,.1)` | `rgba(255,255,255,.11)` | 发丝描边 |
| 阴影 | 两层柔和投影 | 加深一档 | 悬浮层次 |

- 字体栈：`-apple-system, "SF Pro Text", "PingFang SC"` 系统字体，零下载；
- 圆角体系：控件 8px / 卡片 14px / 大区块 20px（主页略放大一档，适配营销页尺度）；
- 图标：全部内联 SVG 手绘，粉彩双色调（浅底 + 主色），对齐 App 图标库风格。

## 2. 页面结构（自上而下）

```
┌─ 粘性导航（玻璃拟态 backdrop-blur，Logo + 6 锚点 + 主题切换）
├─ ① Hero      左文右图：定位语 / 双按钮 / 数字徽章 ｜ 总览页实景截图（macOS 窗框，亮暗双版）
├─ ② 七大页面  「一屏七页」功能卡网格（4+3 两行，每卡图标+定位+要点）
├─ ③ AI 能力   左侧对话演示气泡 · 右侧四项能力列表
├─ ④ 架构      三明治分层图（Swift 壳 / Web 前端 / wbcore）+ 端口族表
├─ ⑤ 工程特点  6 卡网格（零依赖/本地优先/备份/通知/快捷键/多端）
├─ ⑥ 页脚      定位句 + 版本口径 + 文档链接
└─ 回到顶部悬浮钮
```

## 3. 关键组件设计

### 3.1 Hero 实景截图（v1.1 起，替代手绘示意）
- 截图来源：**虚构演示实例**（`tools/make_demo_data.py` 造数后起 8392 实例）+ Playwright 捕获（1280×800 @2x PNG，存 `assets/`），人设「小北」全部为虚构数据；
- macOS 窗框：红黄绿三点 + 发丝分隔的标题条，截图置于其下；整体 `perspective` 微倾 + 悬浮投影，hover 回正；
- **亮暗双版**：`shot-overview.png`（亮）与 `shot-overview-dark.png`（暗）同时挂在 DOM，按 `data-theme` 显隐切换，换主题即换截图；
- 手绘窗口与专注圆环动画已随此变更移除。

### 3.2 功能卡（②区，带实景缩略图）
- 卡片顶部 16:10 **页面实景截图**（`object-fit:cover` 顶对齐，取每页「最有辨识度」的画面：甘特依赖箭头、专注任务池、人生曲线等）；
- 图标 40px 粉彩 chip（每页一个专属色，取自 App KPI 八卡色系）；
- 标题 + 一句话定位 + 3 条要点（色点前缀小字）；
- hover：`translateY(-3px)` + 阴影加深 + 图标 chip 微转 3°。

### 3.3 AI 对话演示（③区）
- 静态构造一轮对话：用户问「总结一下这周」→ AI 分点回答（含 `**加粗**`、列表样式）；
- 底部一行输入框（仅展示，disabled 态）+ 智能体徽章；
- 三智能体以三个胶囊 chip 呈现：Hermes 全能管家 / Muse 规划参谋 / Sage 复盘分析师。

### 3.4 三明治架构图（④区）
- 三层堆叠卡片，自上而下：Swift 壳（窗口/菜单/通知）→ WKWebView 前端（26 模块）→ Python wbcore（SQLite/ICS/CalDAV/AI 代理）；
- 层间用双向箭头标注通信方式（JS Bridge / HTTP 127.0.0.1）；
- 右侧竖排端口族小表：8383 页面+API / 8384 HTTPS ICS / 8385 通知桥；
- 「数据本地存放」注脚：`~/Library/Application Support/P-Workbench3/`。

### 3.5 导航与主题切换
- 粘性顶栏：滚动 > 8px 后从透明变为玻璃拟态（半透明底 + blur + 发丝底线）；
- 当前区块锚点高亮（IntersectionObserver 驱动）；
- 主题钮：太阳/月亮图标切换，亮↔暗 0.25s 过渡；首屏前内联脚本读 localStorage + `prefers-color-scheme` 预设 `data-theme`，**避免暗色用户看到白闪**。

## 4. 响应式

| 断点 | 布局 |
|---|---|
| ≥1080px | Hero 左右双栏；功能卡 4 列；架构图左右双栏 |
| 720–1080px | Hero 保持双栏但窗口示意缩小；功能卡 2 列 |
| ≤720px | 全部单列；导航只留 Logo + 主题钮（锚点收纳进「≡」弹出层）；手绘窗口缩放 0.8 并取消透视 |

## 5. 动效原则

1. 只做「入场渐显（fade + 12px 上移）」「卡片悬浮」「Hero 截图微倾回正」三类，克制不炫技；
2. 全部 CSS transition/animation，JS 只负责 IntersectionObserver 触发时机；
3. `prefers-reduced-motion: reduce` → 关闭全部入场动画与悬浮过渡；
4. 单元素动效时长 0.2–0.5s，曲线 `cubic-bezier(.22,.61,.36,1)`。
